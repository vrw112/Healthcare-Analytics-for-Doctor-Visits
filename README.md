# 🏥 Doctor Visit Analysis

## 📌 Project Overview

**Doctor Visit Analysis** is a data analysis project that explores patient healthcare data to understand patterns in **illness, doctor visits, income, gender, and reduced days of daily activities due to illness**.

The project uses **Python and data visualization techniques** to clean, analyze, and interpret the dataset. Different statistical analyses and visualizations are performed to identify meaningful relationships and patterns within the data.

---

## 🎯 Problem Statement

To analyze patient healthcare data and identify patterns related to **illness, doctor visits, income, gender, and reduced activity days**. The objective is to understand how demographic and health-related factors are associated with healthcare visits and the impact of illness on patients' daily activities.

---

## 🎯 Project Objectives

* Analyze the distribution of patients based on gender.
* Identify the number of male and female patients affected by illness.
* Analyze the relationship between income and the number of doctor visits.
* Identify correlations between different numerical variables.
* Detect missing values in the dataset.
* Analyze the number of reduced activity days due to illness based on gender.
* Use appropriate visualizations to present healthcare-related insights.
* Understand patterns in patient healthcare visits and illness.

## 📊 Data Analysis Performed

### 1. Data Cleaning

* Checked the dataset structure and data types.
* Identified missing values.
* Examined the dataset for inconsistencies.
* Prepared the data for further analysis.

### 2. Gender Analysis

Analyzed the number of male and female patients and visualized the distribution of patients based on gender.

### 3. Illness Analysis

Analyzed the number of patients affected by illness and compared illness-related patterns across genders.

### 4. Income vs Doctor Visits

Analyzed whether patients' income levels are associated with the number of visits made to the doctor.

### 5. Correlation Analysis

Calculated correlations between numerical variables to identify possible relationships within the dataset.

### 6. Reduced Activity Analysis

Analyzed the average number of days of daily activities reduced due to illness based on gender.

```bash

```

### Step 2: Open the Project

Open the project folder in **Jupyter Notebook**, **JupyterLab**, or **Google Colab**.

```bash

```

Open:

